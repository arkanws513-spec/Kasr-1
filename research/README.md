# ملف البحث والتخطيط — KASR-1

هذا المجلد هو المرجع المعماري قبل كتابة المحرك الجديد. يميّز بين ما وجدناه في المشاريع المفتوحة، وما نوصي ببنائه بأنفسنا، وما يحتاج تحققًا عمليًا.

## نطاق المشروع

إنشاء نظام واحد يجمع:
- تعلم مهام جديدة من تعليمات وأمثلة وأدوات.
- تنفيذ المهارات المحفوظة لاحقًا.
- اقتراح حلول جديدة عندما يفشل التنفيذ أو يمكن تحسينه.
- التحقق من النتائج عبر اختبارات مستقلة.
- حفظ سجل الخبرات والمهارات والإصدارات.
- إمكانية إضافة تدريب نموذج محلي خاص بالمشروع في مرحلة لاحقة.

## الفكرة المعمارية المختصرة

`هدف → خطة → مهارة/أدوات مسموحة → تنفيذ معزول → تحقق مستقل → سجل تجربة → اقتراح تحسين → اختبارات مقارنة → اعتماد أو رفض → إصدار قابل للرجوع`

## ما لا نعد به

- لا يوجد «تعلم لأي شيء» من دون نموذج قادر وأدوات وبيانات مناسبة.
- حفظ المهارات والذاكرة لا يساوي تحديث أوزان النموذج.
- تجربة ناجحة واحدة لا تثبت تحسنًا عامًا.
- لن نضع مفاتيح مدفوعة أو API خارجي شرطًا للتشغيل الأساسي.
- لا يمكن ضمان استضافة مجانية دائمة أو تدريب سريع على هاتف فقط.

## قرار البناء الأول

ابدأ بمحرك مهارات موثق + منفّذ مهام محدود + ذاكرة SQLite + مدقق نتائج + مجموعة اختبارات ثابتة. اجعل طبقة النموذج مستقلة. يمكن لمحرك المهارات أن يثبت دورة التعلم على مهام حتمية حتى قبل اكتمال تدريب نموذج اللغة؛ أما المهام المفتوحة التي تتطلب فهمًا وتخطيطًا فستظل محدودة إلى أن يتوفر نموذج مدرّب مناسب.
